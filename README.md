````markdown
AI-Based Tourist Safety Monitoring System

An intelligent tourist safety platform designed to enhance traveler security through real-time monitoring, AI-powered incident detection, geo-fencing, emergency response services, and secure digital identity management.

This project was developed as part of the Master of Computer Applications (MCA) program to address safety challenges faced by tourists while traveling in unfamiliar locations.

---

## Project Overview

The AI-Based Tourist Safety Monitoring System provides a smart and secure environment for tourists by integrating Artificial Intelligence, Geo-Fencing, Blockchain Security, and Real-Time Emergency Response mechanisms.

The system continuously monitors tourist activity, detects abnormal situations, and alerts authorities when emergencies occur. It also provides a secure Digital Tourist Identity and location-aware safety services.
````

```bash
git clone https://github.com/nithyasai05/Smart-Safety-Tourism-App.git
```

